Infrastructure Layer

The Internet ("Net")

The world's largest computer network. A global connection of billions of computers and device networks linked by data cables, routers, and wireless channels.

  • Etymology: Derived from "Interconnection" and "Network".
  • Function: Hardware highway that carries traffic (email, files, web data, VoIP).
  • Key Pioneers: Vinton Gray Cerf & Bob Kahn (TCP/IP co-developers).
Information Layer

World Wide Web (WWW)

A massive collection of interconnected documents, multimedia, and webpages formatted in HTML and accessed through a web browser using HTTP/HTTPS.

  • Hypertext Links: Highlighted keywords/images leading directly to related info.
  • Function: Application service that runs on top of the Internet.
  • Inventor: Sir Tim Berners-Lee (Oxford / MIT Scientist).

Evolution of the Web

From static read-only portals to dynamic social platforms and intelligent semantic web.

Phase 1

Web 1.0

Read-Only Static Web

Web pages were mostly static brochures or digital library directories where users could only view and read.

Key Role: "Information Portal"
Metric: Page Views & Directories
Classic Example: MP3.com, early homepages

Disadvantages:

  • No comments, likes, or sharing
  • Company-focused brochures
  • Lack of web standards
Phase 2

Web 2.0

Read-Write Interactive Web

Emphasizes human collaboration, user-generated content, dynamic applications, and interactive social communities.

Key Features: Folksonomy, Rich UI, User Participation
Business Models: Long Tail & Usage-based plans
Examples: FB, Twitter, IG, Blogs, Wikis, Google Docs
Phase 3

Web 3.0

Read-Write Intelligent Web

Coined by John Markoff. Integrates semantic web technologies, machine learning, NLP, and distributed data.

Core Technology: Semantic Web & AI/ML
Function: Tailored data sharing & smart agents
Advantage: Context-aware personalized results

Internet History & Hall of Fame

Chronological development of global networking and key visionaries from the IT100 syllabus.

Jan 2, 1969

ARPA Experiment & ARPANET

The Advanced Research Projects Agency (ARPA) launched packet-switching network experiments, forming the foundation of the modern Internet.

1982

Coining of the word "Internet"

The term "Internet" officially gained adoption as interconnected networks standardized around TCP/IP protocols.

1986

First "Free Net" Created

Established at Case Western Reserve University, pioneering community-wide free access to digital network resources.

1991

Commercial Access Granted

The US Government allowed commercial business agencies and private enterprises to connect to the Internet backbone.

Key Figures Mentioned in Lecture

Sir Tim Berners-Lee

Inventor of the World Wide Web

English engineer & computer scientist. Professorial Fellow at Oxford University and professor at MIT. He created HTTP, HTML, URL, and the first web server/browser.

Vinton Gray Cerf & Bob Kahn

Fathers of the Internet

Co-designers of the TCP/IP protocols (Transmission Control Protocol / Internet Protocol) which specify how data packets are routed across connected networks.

John Markoff

Technology Journalist

Renowned journalist who suggested and popularized the term "Web 3.0" to describe the next generation of intelligent semantic web tools.

Servers & Network Architecture

How hardware components, server types, ISPs, and DNS work together to deliver online information.

Major Types of Servers (IT100 Syllabus)

Web Server

Serves requested static or dynamic HTML pages and web assets to browsers.

Application Server

Provides the business logic and backend application execution routines.

Proxy Server

Acts as an intermediary gateway security shield between client devices and destination servers.

Mail Server

Receives incoming emails and routes outgoing electronic mail across networks.

File Server

Responsible for central storage and management of shared data files.

Policy Server

Security component in policy-based networks providing authorization and access facilities.

Internet Service Provider (ISP)

National ISP vs. Regional ISP

An organization providing services for accessing and participating in the internet.

National ISP: Business providing internet access in cities & towns nationwide (e.g. PLDT, Converge, Sky Cable).
Regional ISP: Provides internet access to a specific local geographic area.
Addressing & Lookup

DNS & IP Address

Devices communicate using numerical IP addresses, while human users rely on memorable Domain Names.

IP Address: Numerical label assigned to each device for identity (e.g. 192.168.1.1).
Domain Name System (DNS): The "Phonebook of the Internet" translating names (.edu, .com, .gov, .ph) to numerical IPs.
